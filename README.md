# 📄 Invoice Auto-Entry - Lucky Star

Hệ thống tự động nhập hóa đơn đầu vào sử dụng AI (OpenAI GPT-4).

## 🌐 Demo trực tuyến

👉 **[Truy cập tại đây](https://tdatcode.github.io/hoadon.git/)**

## ✨ Tính năng

- 📂 Kéo thả file PDF hóa đơn
- 🤖 Tự động trích xuất dữ liệu bằng AI (OpenAI GPT-4)
- ✏️ Chỉnh sửa dữ liệu trực tiếp trên bảng
- 📊 Xuất Excel theo đúng format kế toán
- 🔐 API key lưu trữ local (bảo mật)

## 🚀 Cách sử dụng

1. Truy cập trang web
2. Nhập **OpenAI API Key** của bạn (lấy tại [platform.openai.com](https://platform.openai.com/api-keys))
3. Kéo thả hoặc chọn file PDF hóa đơn
4. Đợi AI xử lý tự động
5. Kiểm tra và chỉnh sửa nếu cần
6. Xuất file Excel

## 🔑 Lấy OpenAI API Key

1. Đăng ký tài khoản tại [OpenAI Platform](https://platform.openai.com/)
2. Vào [API Keys](https://platform.openai.com/api-keys)
3. Tạo key mới
4. Copy và dán vào ứng dụng

**Lưu ý:** API key chỉ lưu trên trình duyệt của bạn, không gửi đến server nào khác ngoài OpenAI.

## 💻 Chạy local

```bash
# Mở trực tiếp file HTML
# Hoặc dùng server đơn giản:
node server.js
# Truy cập: http://localhost:3000
```

## 📋 Yêu cầu

- Trình duyệt hiện đại (Chrome, Edge, Firefox)
- OpenAI API Key (có phí sử dụng)
- File hóa đơn định dạng PDF

## 🛠️ Công nghệ

- HTML5 + CSS3 + Vanilla JavaScript
- OpenAI GPT-4 API
- PDF.js (đọc PDF)
- SheetJS (xuất Excel)
